Hello Ernesto,

maybe bug#81840 would be interesting to get started? The goal is to tag
most commands to make the M-x command list more organized and more
discoverable. While the edits itself are trivial, one can look into many
user-facing Emacs features, across the whole code base. bug#66335 is
similar. The idea is to improve the finder keyword list, to cover
existing packages better, and this will also help discoverability. Both
of these tasks might be helpful when you want to familiarize yourself

Not yet, but I suppose we can add it. In the meantime, here's a recipe 
adapted from xref--collect-matches, it has been working for some years:

(let ((file buffer-file-name))
   (with-temp-buffer
     (let ((inhibit-modification-hooks t))
       (erase-buffer)
       (insert-file-contents file nil 0 200)
       ;; Xref does not do that, but we might as well.
       (setq-local delay-mode-hooks t)
       (let ((buffer-file-name file)
             (inhibit-message t)
             message-log-max)
         (when (ignore-errors
                 (set-auto-mode t)
                 t)
           (eglot--languageId))))))
