It is common to register "image/.*" handler, however, copying an image into
the clipboard might put into selection multiple mime types matching this
pattern, for example image/png and image/jpeg.  Executing `M-x yank-media
RET' will prompt you to choose a mime type.  Having "image/.*" handler is
essential, because some of image format might be missing in Emacs, and you
still be able to yank a media.  Therefore, `no-query' prefix argument is
added to avoid querying for the mime type and use first matching one.
