Indeed.  I wouldn't be surprised if it was linked to "globalized minor
modes" (font-lock being the prime example at that time, since
`define-globalized-minor-mode` tried to generalize (and improve) the

So it's not at all clear that the problems we had in 2005 are still
with us.

Each warning most probably means that some 'require' is missing.
Native compilation compiles each Lisp file in a separate fresh
instance of Emacs, so any dependency packages that are assumed to be
already loaded, aren't.  If this is the reason, the solution is to add
the missing 'require's.

I don't see how can we help you more than this general advice, since
you didn't show a single warning of those you get.
